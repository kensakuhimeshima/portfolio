# portfolio

### サービス概要
  個人(企業も可)で広告枠の出品や購入ができるサービス。  
  個人経営のカフェや美容室、飲食店、駐車場や自動車、コワーキングスペースまであらゆるスペースを広告枠として販売できる。  
  媒体者は空きスペースを有効活用ができ且つマネタイズもできる。また広告主は自社商品と相性の良い媒体を見つけることができるマッチングサービスです。

### このサービスへの思い・作りたい理由
  現在、一部の業務で広告に携わっています。  
  昨今の広告業界ではweb広告は民主化され、個人や小規模の事業者でも簡単にGDN,YDAやX,meta,TikTokなどのSNS広告を出稿できます。  
  しかし、OOHなどの看板広告や駅広告、デジタルサイネージなどの物理的な媒体は広告代理店を通さなければ購入できず、  
  またそれらの広告は小規模の事業者にとっては代理店マージンを含めると莫大な金額になります。  

  これらの課題を解決するために、個人や小規模事業者でも購入可能な価格帯で購入できる様なサービスを作りたいと考えました。  

### ユーザー層について
  想定しているユーザーは個人でビジネスしている人や小規模事業者を想定。
  
### サービスの利用イメージ
  物理広告を少額から出稿できる。  
  また、さまざまな媒体から自社のプロダクトとマッチする広告枠を探すことができる。

### ユーザーの獲得について
  SNSでの発信。  
  個人経営の飲食店や美容室に営業する。

### サービスの差別化ポイント・推しポイント
  私の知る限り類似のサービスはない。  
  媒体者は期間で広告枠を販売できる。  
  広告にQRコードを設置して、そこからコンバージョンしたらキックバックが入りそこからも収益を上げれる。

### 機能候補
  #### MVPリリース時
  * 会員登録
  * ログイン
  * マイページ
  * 広告枠を販売する(投稿機能)
  * 広告枠を購入する(購入機能)
  * 検索機能(地域、期間、ジャンル、金額)

  #### 本リリース
  * レコメンド機能
  * 閲覧履歴
  * 決済機能
  * カート機能

### 機能の実装方針予定
  Google Maps APIで出稿できる広告を地図上のピンで表示する機能
