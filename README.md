# portfolio

### サービス概要
  広告主(広告を出品したい人)と媒体者(広告枠を売りたい人)をマッチングするサービス。  
  個人経営や小規模事業者が自社のプロダクトと相性の良い媒体や出稿地域を全国から検索できる。  
  町で見かけるような広告が入っていない看板が減らせる可能性のあるサービスです。  

### このサービスへの思い・作りたい理由
  現在、一部の業務で広告に携わっています。  
  昨今の広告業界ではweb広告は民主化され、個人や小規模の事業者でも簡単にGDN,YDAやX,meta,TikTokなどのSNS広告を出稿できます。  
  しかし、OOHなどの看板広告や駅広告、デジタルサイネージなどの物理的な媒体は広告代理店を通さなければ購入できず、それらの広告は小規模の事業者にとってはアクセスが難しいです。  
  方や町で見かけるようないつまでも広告が入っていない看板なども存在します。  
  これら双方の課題を解決するために、個人や小規模事業者でも手軽に広告枠を検索できるようなサービスを作りたいと考えました。  

### ユーザー層について
  想定しているユーザーは個人事業主や小規模事業者を想定。  
  また広告枠を持っているが広告主が決まらない媒体者。  
  
### サービスの利用イメージ
  媒体者は広告枠を投稿でき、広告の詳細(場所、期間、金額、掲載期間)記載できます。  
  物理広告を出稿したい個人事業主や小規模事業者が自社のプロダクトやサービスとマッチする媒体を全国から検索します。  
  購入したい広告枠を見つけたら、「問い合わせ」ボタンを押すと媒体者または広告代理店に連絡が行くイメージです。  

### ユーザーの獲得について
  SNSでの発信。  
  媒体者に無料で掲載させて貰えないか営業します。

### サービスの差別化ポイント・推しポイント
  大型ビジョン向けや交通広告向けのポータルサイトは存在しましたが、町の小規模な看板をまとめたポータルサイトはありませんでしたので、
  そこで差別化できると考えます。  

### 機能候補
